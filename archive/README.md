Retired skills kept for history. `bin/sync-agents` never syncs this folder, and Composer installs exclude it (`export-ignore`).

|---|---|
| `brainstorming` | Its "use before any creative work" trigger collided with planning; replaced by `grill-me` + `writing-plans` |
| `single-flow-task-execution` | Merged into `executing-plans` (review-per-task mode) |
| `finishing-a-development-branch` | Frontier models handle merge/PR/cleanup natively |
| `system-cli-and-bash` | General shell habits models already follow |
| `taste-differential-ui`, `flux-admin-crud` | Folded into the `ui-design.mdc` templates |
| `polyglot-architecture` | Conflicted with the Livewire 4 + FluxUI Pro stack |
| `voice-spec-ingestor`, `ai-media-pipeline`, `auto-research-optimizer` | Experimental; rarely used |
| `writing-skills-reference`, `harden-logic-polyglot` | Long reference material and non-PHP assets moved out of active skills |

To revive a skill, move it back to `skills/` or `optional/`, re-check its description against current models (see the quarterly benchmark in the README), and re-run the sync.
